# Philippines 2028 GATHER landing page

Public page for GATHER, 17–20 October 2028, Cebu, Philippines.
Live at https://linthustone.github.io/gather2028/

## Files
- `index.html`: the whole page (text, styles and settings)
- `assets/`: images, used exactly as supplied (don't crop or trim them)

## Common updates (all in `index.html`)
- **Turn on a button** (nominate, prayer, Road to Cebu, register, contact): find the `GATHER SETTINGS` block near the top and paste the full web address between the quotes.
- **Partner logo links**: in the same block, add each partner's web address under `PARTNERS`. Logos without an address show without a link.
- **Open registration**: in the same block, set `REGISTRATION_OPEN: true` and add the `register` link.
- **Social preview image**: the `og:image` line near the top points to https://linthustone.github.io/gather2028/assets/og-image.jpg. Update it if the site moves.

Venue, fees and internal planning details are intentionally left off this public page.
